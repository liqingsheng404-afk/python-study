## 🎯 项目亮点：教务管理系统

需求：维护和管理学员的成绩信息，包含 7 项功能。

| # | 功能 |
| :---: | :--- |
| 1 | 添加学生信息（姓名 + 语文 / 数学 / 英语） |
| 2 | 修改学生信息（按姓名定位后重新录入） |
| 3 | 删除学生信息（按姓名删除） |
| 4 | 查询学生信息（按姓名查询并输出总分、平均分） |
| 5 | 列出所有学生 |
| 6 | 统计班级成绩（三科最高分 / 最低分 / 平均分，并列出最高分和最低分的学生姓名） |
| 7 | 退出系统 |

**两种实现对比：**

| | 零函数版 | 函数版 |
| :--- | :--- | :--- |
| 用到的知识 | 变量、流程控制、数据容器、字符串方法 | 额外需要 `def`、`enumerate` 等 |
| 输入校验 | `str.isdigit()` | `try / except ValueError` |
| 成绩类型 | 整数 | 支持小数 |
| 代码组织 | 全部在主循环内 | 每个功能一个函数 |

**数据结构**：列表装所有学生，每个学生是一个字典（键 = 字段名，值 = 成绩）。
